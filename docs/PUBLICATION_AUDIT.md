# 공개 전 검토 — 2026-11-17

후속 0.1.8-dev는 공식 계정 자동 시험에서 발견한 최근 25개 선택·개별 숫자 지연을 수정했습니다. 변경 범위는 생성 시각 우선 SQL과 이벤트 후 활성 알림 1회 갱신이며 새 네트워크·DB 쓰기·권한·타사 구현을 앱에 추가하지 않습니다. 시험용 PC 발송 도구는 별도이며 `.mpp`에는 포함되지 않습니다. 아래 0.1.7 해시·대조 수치는 당시 검토 기록이고, 0.1.8의 해시·파일 점검·대응 소스 재빌드 결과는 새 검토 묶음의 `audit-report.json`, 실행 검증은 `DEVICE_TESTS.md`에 기록합니다. 원격 릴리스 설정이 남아 있다는 판단은 같습니다.

검토 대상은 기기에 설치해 시험한 0.1.7-dev 패치 묶음과 현재 소스입니다. 확인한 범위에서는 **출처를 숨긴 타사 코드 재배포는 발견하지 않았습니다.** 공개 GPL 코드의 수정·재사용은 있으며, ‘전부 처음부터 만든 코드’라고 소개하면 안 됩니다. GPL 조건 이행과 LINE 서비스 약관·앱 저작권은 별개의 문제입니다. 이 기록은 전 세계 코드에 대한 표절 검색, 법률적 적법성 인증, 계정 안전 보증을 뜻하지 않습니다.

## 서비스·계정 관련 한계

LINE을 수정했다는 사실과 공개 GPL 코드 사용 허가는 서로 다른 사안입니다. LY 약관에는 부당한 목적·방식의 역공학 제한, 소프트웨어 권리, 위반 등에 따른 서비스 제한·계정 삭제 규정이 있습니다. 이 패치가 개별 지역 법률·약관 아래 허용되는지, 운영사가 제재하는지까지 기술 시험으로 확정할 수 없습니다. [현재 LY/LINE 약관](https://terms.line.me/line_terms?lang=en)

특히 **Restore push registration**은 Firebase Installations 등록 요청의 `X-Android-Cert`를 원본 인증서 식별값으로 바꿉니다. 원본 개인키를 포함하거나 APK 서명을 위조하는 것은 아니지만, 서버에 보고하는 식별값을 수정하는 동작입니다. 단순한 화면 표시 변경과 동일하게 설명해서는 안 됩니다. 현재 선택형·기본 미선택이며 사용자 안내에도 동작을 명시해야 합니다. 이를 써도 계정 위험이 없다는 보장은 없습니다.

GPL로 배포하는 확장이 비공개 LINE 앱에 결합되는 점도 법률적 쟁점이 될 수 있습니다. 이 검토는 그 결합의 적법성을 확정하지 않습니다. 공개 패치와 대응 소스를 중심으로 배포하고, 권리가 없는 원본·패치된 전체 LINE APK를 함께 배포하지 않는 구성을 제안합니다.

결론: **출처와 GPL 재사용 관계를 공개한 패치·대응 소스의 시험 배포 자료는 준비할 수 있습니다. 현재 폴더를 그대로 공식 배포 완료 상태라고 볼 수는 없고, 원격 릴리스 연결과 유지보수자 정보는 남아 있습니다.**
