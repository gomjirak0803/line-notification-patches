# 카카오톡 알림 표시 방식 참고

사용자가 제공한 카카오톡 26.9.2(versionCode 29260920) APKM을 2026-11-17 로컬에서 분석했습니다. 카카오톡 코드·이미지·리소스를 LINE에 포함하지 않고, 확인한 공개 Android 알림 API 사용 방식을 참고했습니다.

- APKM SHA-256: `83bde3fa2aa8652ab2fabdcba7cdf0fc6d0258ccc60bba2e956a2594ebdff7ac`
- base.apk SHA-256: `9b8f3cb7a7d31219fd022d28874cbec774c3fedaefee1e60aff34b3449a30983`
- APK의 v3 서명 검사를 통과했습니다. 인증서 SHA-256은 `2b06cc3d47782d7c497c07f17cb5f859cd6bbcb66829f3e67b96b7a44820d2ce`입니다.
- 제공된 APK는 최소 API 32입니다. S10e(API 31)에 카카오톡을 설치하지 않았으며, 분석과 합성 알림 렌더링으로 표시 방식을 확인했습니다.

## APK에서 확인한 경로

`ChatNotifier.p`는 `o55.c()`의 Android API 30 이상 조건에서 `r` 경로를 사용합니다. 내용 표시 설정에 따라 `r`은 `L`의 대화형 알림 또는 `F`의 BigText 표시를 선택합니다.

`ChatNotifier.L`은 본문·시간·발신자 Person을 메시지 객체에 담아 기존 알림의 메시지를 추가하거나 교체합니다. 호환 라이브러리의 `zsd0.n`은 Android `Notification.MessagingStyle`로 연결되며, 메시지 목록이 25개를 넘으면 가장 오래된 항목을 제거합니다. 메시지 수와 별도로 `r`은 카카오톡의 전체 미확인 수를 `setNumber`에 전달합니다.

발신자 이름은 Person에, 그룹 여부는 `setGroupConversation`에 전달합니다. 카카오톡의 새 스타일 생성 경로에는 별도의 `setConversationTitle` 호출이 없으며, 방 제목은 `k0`의 대화 바로가기 등록과 `setShortcutId` 경로에도 전달됩니다. 따라서 카카오톡이 자체적인 숫자 음영 텍스트 뷰를 만든다고 해석하지 않았습니다.

사진·이모티콘은 별도의 처리입니다. `L`에는 존재하는 파일의 URI를 메시지에 넣는 분기가 있지만, 앞선 `r`은 미디어 로딩을 시도하기도 합니다. LINE 패치는 이 로딩 경로를 도입하지 않았습니다.

## LINE 0.1.7에 적용한 범위

기존 0.1.6은 다섯 개의 TextView에 `발신자: 본문`을 각각 한 줄로 넣었습니다. 0.1.7은 읽기 전용 로컬 조회의 최근 미확인 메시지 최대 25개와 안정적인 발신자 ID를 공개 `MessagingStyle` API에 전달합니다. 연속 발신자의 묶음, 여러 줄 본문, 실제 노출량은 기기의 시스템 UI가 결정합니다. **25개는 전달·보관 상한이며 화면에 25줄을 보장하지 않습니다.** [Android 대화형 알림 안내](https://developer.android.com/develop/ui/compose/notifications/expanded#message-style), [MessagingStyle API](https://developer.android.com/reference/android/app/Notification.MessagingStyle)

- 전체 미확인 수는 기존처럼 LINE의 값을 사용합니다. 83개 중 최근 25개를 표시해도 제목은 `[83]`입니다.
- S10e의 시스템 템플릿이 제목의 배경색 span을 제거하는 것을 확인했습니다. 사용자 선택에 따라 `방 이름 [6]` 표기를 사용합니다.
- 그룹은 별도 대화 제목을 사용하고, 1:1은 시스템의 상대방 제목 자리에 방 이름과 숫자를 표시합니다. 발신자 구분에는 표시명이 아닌 계정·발신자 ID를 사용합니다.
- LINE의 기존 바로가기·클릭 경로는 유지하며 새 대화 바로가기를 등록하지 않습니다. 사진을 추가로 내려받지 않고, 내용 없는 첨부는 기존 안내 문구로 표시합니다.
- 기존 읽음/답장 PendingIntent, 공개 알림, 잠금화면 공개 범위, 조용한 채널과 완전 숨김 처리는 유지합니다. 저장 완료 확인·계정 확인·읽음 경계도 그대로 사용합니다.
- 이전 사용자 지정 뷰와 스타일 메타데이터를 제거한 뒤 새 스타일을 적용합니다. 내용 숨김으로 갱신할 때는 대화 제목·메시지·Person 메타데이터도 함께 제거합니다.

## 확인 범위

S10e에서 실제 제품 렌더러를 임시 독립 앱에 넣어 합성 데이터로 1:1 1개, 그룹 7개, 전체 83개 중 최근 25개를 렌더링했습니다. 실제 알림을 게시하거나 LINE 계정을 사용하지 않았습니다. 발신자·본문은 약 13.03sp로 표시됐으며, 그룹의 방 이름은 시스템 상단 제목줄(약 10sp)에 표시됐습니다. 시스템이 높이에 맞춰 오래된 메시지를 숨기는 것도 확인했습니다. 이는 실제 수신·잠금화면 전체 시험을 대신하지 않으며, 설치 및 실수신 결과는 `DEVICE_TESTS.md`에 별도로 기록합니다.
